# 📊 EDA Task – Superstore Dataset

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Superstore dataset using Python.

The main objective is to understand the dataset, analyze sales and profit, identify relationships between numerical variables, and visualize important business insights using different charts.

---

## 🎯 Objectives

The following EDA tasks are performed in this project:

- Load the Superstore dataset and display the first 5 rows.
- Analyze the basic structure and information of the dataset.
- Check for missing values.
- Generate statistical summaries.
- Create a bar plot to show total Sales for each Category.
- Create a box plot to visualize Profit distribution.
- Create a scatter plot between Discount and Profit.
- Create a correlation matrix for numerical columns.
- Visualize the correlation matrix using a heatmap.
- Find the Category with the highest total Profit.
